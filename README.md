# Chisato Nakashima – Portfolio

Live: https://chisato-portfolio.vercel.app

## About

Frontend Engineer & UI/UX Designer based in Melbourne.
Built with Next.js 16 + TypeScript + Tailwind CSS.

## Features

Built with reusable,loosely-coupled React components.
Showing my projects, skills, and process of work with simple and clean interface.

## How to Run

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
